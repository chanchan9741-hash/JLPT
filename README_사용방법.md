# 🎌 JLPT MASTER - 실전 문제 풀이 & 스마트 오답노트 프로그램

JLPT MAX 실전 기출 문제(N1~N5, 총 7,661문항)를 인터랙티브하게 풀고, **틀린 문제를 실시간으로 자동 수집하여 지속적으로 복습할 수 있는 모던 웹 애플리케이션**입니다.

별도의 복잡한 설치나 웹 서버 실행 없이, **`index.html` 파일을 더블 클릭하기만 하면 브라우저(Chrome, Edge 등)에서 즉시 실행**됩니다.

---

## 🚀 빠른 시작 (실행 방법)

1. 폴더 안에 있는 **`index.html`** 파일을 더블 클릭하여 엽니다.
2. 원하는 급수(N1~N5)와 문제 유형을 선택하고 바로 문제를 풉니다.
3. 키보드 숫자키 **`1`, `2`, `3`, `4`** 또는 마우스 클릭으로 정답을 선택합니다.

---

## ✨ 핵심 기능 안내

### 1. 실전 퀴즈 & 즉각적인 피드백 (Quiz Mode)
- **7,661 전 문항 완전 탑재**:
  - N1: 2,020문항 | N2: 1,742문항 | N3: 1,621문항 | N4: 1,661문항 | N5: 617문항
  - 문맥 규정, 한자 읽기, 표기, 유의 표현, 용법, 단어 형성 등 영역별 필터 지원
- **시각 & 사운드 피드백**:
  - 정답 시: 상쾌한 화음 효과음과 함께 에메랄드 그린 하이라이트
  - 오답 시: 부드러운 알림음과 함께 내가 찍은 오답(빨강)과 실제 정답(초록)을 동시 표시
- **풍부한 해설 제공**:
  - 정답 완성 문장 및 한국어 전체 해석
  - 출제 의도 핵심 포인트
  - 각 보기(①, ②, ③, ④)별 오답 및 정답 상세 분석 수록
- **후리가나(루비) ON/OFF 토글**:
  - 실전 시험처럼 한자만 보고 풀고 싶을 때는 후리가나를 끌 수 있습니다 (`F` 키).
- **3가지 문제 풀이 스타일 지원**:
  - **⚡ 즉시 풀기**: 1문제 풀 때마다 즉시 정답 및 상세 해설 확인
  - **🔁 안키 빈도 반복 (스마트 취약점 반복)**: 자주 틀린 문제가 더 자주, 맞힐 때까지 반복 출제되는 안키식 스마트 반복 (틀린 문제는 3문제 뒤에 다시 재출제!)
  - **⏱️ 모의시험**: 타이머와 함께 실전처럼 풀고 나중에 일괄 채점

### 2. 안키 스마트 망각곡선 복습 (Anki SRS Mode)
- **에빙하우스 망각곡선 기반 분산 반복 (SM-2 알고리즘)**:
  - 단순 1회성 풀이에 그치지 않고, 뇌가 잊어버릴 최적의 시점(1일→3일→7일→21일)에 복습 카드가 자동으로 배달됩니다.
- **2가지 복습 모드 지원**:
  - **🃏 플래시카드 모드**: 문제를 보고 스스로 정답을 떠올린 뒤 `Space`로 카드를 뒤집어 정답·완성문·상세 해설을 확인
  - **⚡ 실전 풀이 모드**: 보기 1~4번을 직접 찍어보고 맞힘 여부에 따라 난이도 평가
- **Anki 4단계 난이도 평가 버튼**:
  - 🔴 **다시 (Again - 1번 키)**: 1일 후 다시 복습 (세션 끝에 재출제되어 완전 정복 유도)
  - 🟠 **어려움 (Hard - 2번 키)**: 간신히 기억남 (완만한 간격 증가)
  - 🟢 **알맞음 (Good - 3번 키)**: 적절히 기억남 (표준 SM-2 간격 증가)
  - 🔵 **쉬움 (Easy - 4번 키)**: 너무 쉬움 (긴 간격 보너스)
- **스마트 덱 빌더 & 스케줄러**:
  - 오늘 복습할 카드, **🎯 자주 틀린 순 반복 (오답 빈도 가중치)**, 오답노트 전체 카드, 북마크 카드, 전체 푼 문제 중 선택 복습 가능
  - 내일 복습할 카드를 오늘 미리 당겨서 복습할 수 있는 **"미리 당겨서 복습"** 지원
  - 급수 및 유형별로 새 문제를 10~50개씩 복습 덱에 추가하는 **"새 문제 덱 추가"** 기능 수록

### 3. 실시간 자동 갱신 스마트 오답노트 (Mistake Notebook)
- **틀리면 알아서 자동 등록**:
  - 문제를 틀리는 순간, 문제 내용·내가 고른 오답·틀린 횟수·날짜가 오답노트에 자동으로 저장되고 **안키 복습 덱(Again 1일)** 에도 즉시 등록됩니다.
- **오답 집중 테스트 (Review Test)**:
  - 오답노트 탭에서 **"오답 집중 테스트"** 버튼을 누르면, 지금까지 틀린 문제들만 쏙 뽑아서 바로 다시 풀어볼 수 있습니다.
- **정복(마스터) 시스템**:
  - 오답 문제를 다시 풀어 맞히면 자동으로 **"✨ 정복 완료"** 상태로 승급되어 복습 성취도를 체감할 수 있습니다.
- **다양한 파일 형식으로 오답노트 내보내기**:
  - **📄 PDF 인쇄 / 저장**: A4 규격의 깔끔한 오답노트 & 학습 보고서 출력 (브라우저 인쇄창에서 'PDF로 저장')
  - **📊 엑셀 / CSV (.csv)**: 한글/일본어가 깨지지 않는 UTF-8 BOM 엑셀 호환 스프레드시트 파일 즉시 다운로드
  - **마크다운 (.md)**: Google NotebookLM, Notion, 옵시디언, 벨로그 등에 바로 업로드할 수 있는 문서 파일
  - **💾 JSON 백업**: 전체 학습 이력과 오답노트를 담은 데이터 백업 파일 (동기화 센터 또는 학습 분석 탭)

### 4. 학습 분석 대시보드 (Analytics)
- 누적 푼 문제 수, 전체 정답률, 현재 대기 중인 오답 수, 정복 완료 문항 수 실시간 집계
- 급수별 학습 진행률 및 정답률 프로그레스 바
- 문제 유형별 취약도 분석 (내가 한자 읽기에서 많이 틀리는지, 용법에서 많이 틀리는지 한눈에 파악)

### 5. 데이터 영구 저장 & 클라우드/오프라인 동기화
- 모든 학습 기록, 오답노트, 안키 복습 덱, 북마크는 브라우저 내부 로컬 저장소(`localStorage`)에 자동 보존되므로 인터넷 연결이 없어도 언제든지 이어서 풀 수 있습니다.
- Google 계정 로그인 또는 JSON 백업/복원을 통해 모바일과 PC 간 100% 동기화됩니다.

## ⌨️ 키보드 단축키

### [실전 퀴즈 풀이]
| 키 | 동작 |
| :---: | :--- |
| **`1` `2` `3` `4`** | 보기 1번~4번 선택하기 |
| **`Space`** or **`Enter`** | 다음 문제로 이동 (해설 확인 후 바로 다음 문제) |
| **`P`** | 이전 문제로 이동 |
| **`N`** | 다음 문제로 이동 |
| **`F`** | 후리가나(루비 읽기) 켜기 / 끄기 토글 |
| **`T`** | 한글 뜻/해석 표시 토글 |
| **`B`** | 현재 문제 중요 북마크(★) 추가 / 해제 |

### [안키 스마트 복습]
| 키 | 동작 |
| :---: | :--- |
| **`Space`** or **`Enter`** | 정답 및 해설 카드 뒤집기 (앞면 ↔ 뒷면) |
| **`1`** | 🔴 **다시 (Again)**: 1일 후 다시 복습 |
| **`2`** | 🟠 **어려움 (Hard)**: 단기 간격 복습 |
| **`3`** | 🟢 **알맞음 (Good)**: 표준 간격 복습 |
| **`4`** | 🔵 **쉬움 (Easy)**: 장기 간격 복습 |
| **`F`** / **`T`** / **`B`** | 후리가나 / 한글 해석 / 북마크 토글 |
